# tiny-chess

A chess engine in under 4 KB of Python: a 10x12 mailbox board, alpha-beta with a transposition table, quiescence, check extensions, null move and late move reductions, searched under a fixed node budget so every move is reproducible. `main.py` is the packed entry; it plays the make.fun gauntlet through `MAKEFUN_ENV_URL`.
